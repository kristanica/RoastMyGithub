# RoastMyGitHub

## Overview

RoastMyGitHub is an AI-powered web application that analyzes GitHub profiles and repositories and generates entertaining, brutally honest, but constructive feedback.

The platform combines humor and technical analysis to help developers improve their GitHub presence, portfolio quality, and project presentation.

---

# Problem

Many developers do not know how their GitHub profile appears to:

- Recruiters
- Hiring managers
- Senior developers
- Open source maintainers

Traditional portfolio reviews are often boring, expensive, or difficult to obtain.

RoastMyGitHub makes portfolio feedback entertaining and accessible.

---

# Mission

Help developers improve their GitHub profiles through humor.

Every roast should:

1. Make the user laugh.
2. Reveal genuine issues.
3. Provide actionable recommendations.
4. Encourage profile improvement.

---

# Target Users

## Primary Users

- Student developers
- Junior developers

- Bootcamp graduates
- Open source contributors

---

## Secondary Users

- Recruiters
- Tech content creators
- Coding communities
- Engineering managers

---

# Core User Flow

1. User visits the website.
2. User enters a GitHub username.
3. User clicks "Roast Me".
4. Application fetches public GitHub data.
5. AI analyzes the profile.
6. AI generates a roast.
7. User shares results.

The process should take less than 10 seconds.

---

# MVP Features

## Profile Roast

Analyze:

- Bio
- Profile completeness
- Repository count
- Pinned repositories
- Languages used
- Activity level
- README quality

Generate:

- Roast Score
- Portfolio Grade
- AI Roast
- Strengths
- Weaknesses
- Suggestions

---

## Repository Roast

Input:

- GitHub repository URL

Analyze:

- README
- Project structure
- Naming conventions
- Documentation
- Repository quality

Generate:

- Repository Score
- AI Roast
- Technical Feedback
- Improvement Suggestions

---

## Shareable Results

Users should be able to:

- Copy roast
- Share roast
- Download roast image

Results should be optimized for screenshots.

---

# Roast Style

Tone:

- Funny
- Sarcastic
- Playful
- Constructive

The AI should feel like a senior developer reviewing a portfolio.

---

## Example Roast

"Your GitHub profile has 47 repositories, yet somehow none of them contain a README. That's not a portfolio, that's digital archaeology."

Followed by:

- Why documentation matters
- What should be added
- Examples of improvement

---

# Success Criteria

A successful roast:

- Is funny
- Is technically accurate
- Provides value
- Encourages improvement

---

# Non-Goals

Do NOT build:

- Social networking features
- Messaging systems
- GitHub clone features
- Team collaboration tools
- Project hosting
- Complex dashboards

RoastMyGitHub is a roast engine, not a developer platform.

---

# Authentication

Authentication is NOT required for the MVP.

Users should be able to:

- Enter a GitHub username
- Roast a public profile
- Roast a public repository

without creating an account.

---

# Future Features

# North Star

A developer should be able to visit RoastMyGitHub, enter a username, get roasted, laugh, learn something useful, and share the result within one minute.

# STYLE GUIDE — RoastMyGitHub

RoastMyGitHub is a minimalist interface with chaotic AI-generated output.

The UI is calm. The personality is not.

---

## 🎨 Visual Design

- Minimal layout
- Dark theme only
- No decorative elements
- Strong use of whitespace

### Colors

- Background: `#0B0F14`
- Surface: `#111827`
- Border: `#1F2937`
- Primary Text: `#E5E7EB`
- Secondary Text: `#9CA3AF`
- Accent: `#FF3B3B`

Accent is used sparingly.

---

## 🔤 Typography

- Font: `Inter`
- Mono: `JetBrains Mono` (for repo/code references only)

### Rules

- Clean hierarchy
- No stylized fonts
- No text effects
- Emphasis comes from spacing and line breaks

---

## 📐 Layout

- Single column
- Centered content
- Max width: 640–720px
- Linear vertical flow

No navigation. No panels.

---

## 🧩 Components

### Input

- Simple URL input
- Placeholder: "Paste GitHub repo URL"

### Button

- Minimal styling
- Hover: subtle color shift only
- No animations beyond basic transitions

---

## 💬 Output Style (Chaos Layer)

The UI is minimal, but the **text behavior is intentionally chaotic**.

### Rules:

- Short sentences mixed with sudden longer observations
- Uneven pacing
- Occasional abrupt tone shifts
- Slight unpredictability in phrasing
- Developer humor, but not stable or “polished”

### Example output style:

- "This is fine."
- "Actually no."
- "Why are there 6 different patterns in one file."
- "You tried. That’s the issue."

---

## ⚡ Loading States

Loading messages are part of the chaos layer.

Rotate or randomly select:

- "Analyzing your decisions…"
- "This might hurt."
- "Parsing technical debt…"
- "Looking for structure… failed."

No progress bars unless minimal.

---

## 🧱 Output Structure

Roasts are not strictly structured.

They may include:

- observation
- contradiction
- short judgment
- abrupt final line

No rigid formatting rules.

---

## 🎭 Tone System

### Allowed:

- sarcastic
- slightly unstable commentary
- humorous bluntness
- observational critique

### Not allowed:

- cruelty without context
- spammy insults
- meme overload
- emojis as decoration

---

## ⚡ Motion

- Very minimal transitions (150–200ms)
- No bouncy or playful animations
- Occasional subtle jitter in text appearance allowed (very light)

---

## 🚫 Avoid

- dashboards
- UI clutter
- heavy animations
- polished SaaS tone
- overly structured “enterprise UX”

---

## 🧠 Core Principle

The UI is controlled.

The output is not.

Minimal surface. Chaotic voice.
